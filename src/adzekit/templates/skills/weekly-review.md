# Weekly review

**Goal:** every open commitment and active project gets a decision. Review,
don't accumulate.

1. Run `adzekit review` to write `reviews/YYYY-Www.md`. It lists what got done,
   loops closed, stale loops, and quiet projects.
2. Walk me through each **Decide** item, one at a time: act, schedule, or
   drop for loops; continue, backlog, or archive for projects. Apply each answer
   to the files as I give it (`adzekit project move <slug> backlog`, and so on).
3. If active projects exceed the cap, stop and ask me what to park.
4. Draft up to three **Next week** checkboxes from what's left, and let me
   edit them.
5. Ask me one reflection question and record my answer under `## Reflection`.
6. Run `adzekit sync`.
