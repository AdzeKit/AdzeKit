# Daily start

**Goal:** a daily note with at most five intentions I actually chose.

1. Create today's note: run `adzekit today`, or copy the template from the
   last note by hand. Unfinished intentions carry forward automatically.
2. Read `loops/active.md`. List loops that are overdue or older than the
   stale threshold in `.adzekit`.
3. For each one, ask me: **act today, reschedule, or drop?** One question at a
   time, one-line answers.
4. Write the result to `## Intention`: at most five checkboxes, most important
   first. If more than five compete, show me the trade-off instead of adding a
   sixth.
5. Reply with the five intentions and nothing else.

Don't read email, chat, or calendars unless I ask. This routine works from the
workspace alone.
